# Code of Conduct

## The short version

Be decent. Assume good faith. Critique code, not people.

## Standards

Behaviour that helps: welcoming newcomers, accepting constructive feedback, focusing on what is
best for the people using this project, and showing empathy toward other contributors.

Behaviour that does not: harassment of any kind, personal or political attacks, publishing other
people's private information, sexualised language or imagery, and sustained disruption of
discussion.

## Scope

Applies in all project spaces — issues, pull requests, discussions — and when representing the
project publicly.

## Enforcement

Report to ivan.vydrin.99@gmail.com. Reports are handled privately, and a reporter's identity is not
shared with the person reported.

The maintainer may remove comments, close issues, or block accounts. This project is small enough
that "the maintainer decides" is the honest description of the process; a committee structure here
would be fiction.
