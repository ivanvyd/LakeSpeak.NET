# 0.6.0 release evidence

Stable release completed on 2026-11-28 from signed tag `v0.6.0`, commit
`3e876eeb8d985de97ce112a00b773bcb402ac25f`.

The [signed-tag publication](https://github.com/ivanvyd/LakeSpeak.NET/actions/runs/46123825775)
built, tested, packed and attested the release, then published after the `nuget` environment was
approved. GitHub verifies the tag signature, and `git verify-tag` passed against
`.github/allowed_signers`. Before tagging, CI and Security passed on `main` at the same commit.

Both public NuGet packages, `LakeSpeak.Genie` and `LakeSpeak.Cli` 0.6.0, name that commit in their
repository metadata and pass `dotnet nuget verify --all`.

Fresh public-feed consumers, restored into an empty package cache, passed their offline HTTP
fixtures: the [package quickstart](../../examples/package-quickstart/README.md) on .NET 8 and the
[strict results consumer](../../examples/strict-results-consumer/README.md) on .NET 8 and .NET 10.
The public `LakeSpeak.Cli` 0.6.0 tool installed into a new tool directory, reported
`0.6.0+3e876eeb8d985de97ce112a00b773bcb402ac25f`, generated a starter pack and validated it.

All three platform archives on the [GitHub release](https://github.com/ivanvyd/LakeSpeak.NET/releases/tag/v0.6.0)
match `SHA256SUMS.txt` and pass provenance verification pinned to this repository's release
workflow and the exact source commit. The self-contained Windows binary ran and reported the
release version. Linux and macOS binaries were not run locally.

The [live smoke suite](https://github.com/ivanvyd/LakeSpeak.NET/actions/runs/46122744471) passed
ten tests on .NET 10 against the AWS CI Agent, including strict results, at `197adfb`. The release
commit differs from it only in `docs/compatibility.md`. No live workspace run used the installed
0.6.0 packages, and GCP remains untested.
