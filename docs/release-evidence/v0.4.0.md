# 0.4.0 release evidence

Stable release completed on 2026-11-07 from signed tag `v0.4.0`, commit
`2563594b9e29612b5fc270ccab07b6ded7f8599f`.

The [nonpublishing rehearsal](https://github.com/ivanvyd/LakeSpeak.NET/actions/runs/42364245042)
passed before the [signed-tag publication](https://github.com/ivanvyd/LakeSpeak.NET/actions/runs/42364657820).
GitHub verifies the tag signature. Both public NuGet packages identify that commit, pass
`dotnet nuget verify --all`, and match the attested workflow payloads apart from NuGet's added
repository signature. Provenance verification required this repository's release workflow,
the exact source commit and a GitHub-hosted runner.

Fresh public-feed consumers passed the offline HTTP query fixture on .NET 8 and .NET 10.
The public `LakeSpeak.Cli` 0.4.0 tool installed into a new tool directory and package cache,
reported the release version, generated a pack containing `requireQueryResult: false`, and
validated that pack. A separate installed SDK consumer returned its expected query result.

All six [release assets](https://github.com/ivanvyd/LakeSpeak.NET/releases/tag/v0.4.0) match the
workflow artifact hashes. Checksums and provenance passed for all three platform archives;
the self-contained Windows binary ran successfully. Linux and macOS binaries were not run
locally. No live Databricks workspace execution was performed.
